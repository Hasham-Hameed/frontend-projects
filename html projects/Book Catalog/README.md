# Book Catalog Page

A simple HTML page that displays a catalog of programming books in a table. Built with semantic HTML only (no CSS or JavaScript yet).

**[View Live Demo](https://hasham-hameed.github.io/frontend-projects/html%20projects/Book%20Catalog/index.html)**

> Part of my [frontend-projects](https://github.com/Hasham-Hameed/frontend-projects) repository, a collection of HTML, CSS and JavaScript practice projects.

## Features

- Structured data table using `<table>`, `<thead>`, `<tbody>` and `<tfoot>`
- Header cells defined with `<th>` for better accessibility
- A footer row spanning all columns with `colspan="4"` to show the total book count
- Responsive viewport meta tag for mobile screens

## Table Columns

| Column | Description |
|--------|-------------|
| Title | Full title of the book |
| Author | Name of the author |
| Genre | Topic or category of the book |
| Publication Year | Year the book was published |
