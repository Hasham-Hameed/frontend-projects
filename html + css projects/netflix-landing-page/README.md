# Netflix Landing Page

A practice recreation of a streaming service landing page, built with HTML and CSS. It features a full-screen background image with a dark overlay, a header with a logo and sign-in button, and a centered email sign-up form.

**Live demo:** https://Hasham-Hameed.github.io/frontend-projects/netflix-landing-page/

## What it includes

- Full-page background image with a dark gradient overlay for readable text
- Header with a logo on the left and a red "Sign In" button on the right
- Large centered heading, pricing line, and call-to-action text
- Email input and a gradient "Get Started" button
- Layout built with flexbox

## How to view

No build steps or dependencies needed. Open `index.html` in your browser, or visit the live demo link above.
