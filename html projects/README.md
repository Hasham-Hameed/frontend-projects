# HTML Projects

A collection of small projects I built while learning HTML. Each project lives in its own folder with its own README, and every one has a live demo hosted on GitHub Pages.

> Part of my [frontend-projects](https://github.com/Hasham-Hameed/frontend-projects) repository.

## What These Projects Cover

- Semantic page structure (`header`, `main`, `section`, `footer`)
- Forms and built-in HTML validation
- Tables and accessible data presentation
- Accessibility basics (labels, `fieldset`, `legend`, `th`)

## Running Any Project Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Hasham-Hameed/frontend-projects.git
   ```
2. Open a project folder, for example:
   ```bash
   cd "frontend-projects/html projects/Hotel feedback form"
   ```
3. Open its `index.html` in your browser.
