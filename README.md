# Front-End Projects

A collection of small HTML, CSS, and JavaScript projects I'm building while learning front-end web development. Each project lives in its own folder, and new ones are added as I make them.

## Projects

| Project | What it is | Skills practiced |
|---|---|---|
| [Netflix Landing Page](./netflix-landing) | A practice recreation of a streaming service landing page with a hero section, sign-in button, and email sign-up form | HTML, CSS, flexbox, background overlays, form styling |

JavaScript projects will be added here as I build them.

## How to view a project

No build steps or dependencies needed. Open the project's folder and double-click its `index.html` file to view it in your browser.
