# Tech Conference Schedule

A simple HTML page that displays a conference schedule in a table, organized by time and track. Built with semantic HTML only (no CSS or JavaScript yet).

**[View Live Demo](https://hasham-hameed.github.io/frontend-projects/html%20projects/Conference%20Schedule/index.html)**

> Part of my [frontend-projects](https://github.com/Hasham-Hameed/frontend-projects) repository, a collection of HTML, CSS and JavaScript practice projects.

## Features

- Accessible data table using `<table>`, `<caption>`, `<thead>` and `<tbody>`
- `<caption>` that describes the table for screen readers
- Header cells defined with `<th>` and the `scope` attribute
- Time slots as row headers, tracks as column headers
- Break and lunch rows that sit alongside the session rows
